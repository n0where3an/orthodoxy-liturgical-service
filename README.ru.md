# orthodoxy-liturgical-service

Генератор последований православного богослужения суточного круга по
Русскому Типикону: на заданную дату собирает службу из текстов Часослова,
Служебника, Октоиха, Минеи (месячной и общей), Ирмология, Псалтири, Апостола
и Евангелия.

[English version](README.en.md) · [Оглавление](README.md)

## Быстрый старт

Нужны: Go, PostgreSQL, `unrar`, локальная копия orthlib.ru.

```sh
cp .env.example .env            # DATABASE_URL, ORTHLIB_DIR, PONOMAR_DIR
scripts/extract-orthlib.sh      # архивы RAR -> var/orthlib/*.hip
go build -o var/liturgy ./cmd/liturgy
var/liturgy migrate
scripts/extract-english.sh      # Coverdale PDF -> var/english/coverdale.txt (необязательно)
var/liturgy import -v           # церковнославянский корпус (чтения — если задан PONOMAR_DIR); английский — если ENGLISH_MD_DIR / coverdale.txt
var/liturgy plan   -date 2026-11-12 -service first_hour      # план службы в JSON
var/liturgy render -date 2026-11-12 -service third_hour -mode kliros -o terce.html
var/liturgy serve                                   # http://127.0.0.1:8080/?date=2026-11-12&service=sixth_hour&mode=laity
var/liturgy temples                                 # список посвящений храмов для -temple
```

## Службы и параметры

Службы: `vespers` (вечерня), `matins` (утреня; без `-standalone`
соединяется с первым часом), `first_hour`, `third_hour`, `sixth_hour`,
`ninth_hour` (часы), `liturgy` (литургия свт. Иоанна Златоуста). Что именно
поддерживается — в разделе [Покрытие](#покрытие).

| Параметр | Значение |
|---|---|
| `-date ГГГГ-ММ-ДД` | дата по гражданскому (новому) стилю; `-julian` — по старому |
| `-service` | `vespers`, `matins`, `first_hour` … `ninth_hour`, `liturgy` |
| `-reader` | чин без священника (мирской чин) |
| `-deacon` | ектении говорит диакон |
| `-standalone` | час отдельно (обычное начало, отпуст); по умолчанию часы соединяются, как принято в приходах |
| `-typikon` | по Типикону там, где приходская практика иная: канон утрени поётся со стихами библейских песней; летом в воскресенье вместо полиелея — 17-я кафизма |
| `-psalmody short\|sung\|read` | стихи псалмов до первой стихиры там, где начало поётся: на «Господи, воззвах» от «Положи, Господи, хранение», на хвалитех при поемом славословии — `short` (по умолчанию: сразу к стиху первой стихиры), `sung` (поются) или `read` (читаются). При читаемом славословии хвалитны читаются |
| `-temple <id>` | в честь кого освящён храм: id из `liturgy temples` (`data/calendar/temples.yaml`) или день Минеи `me.ММ.ДД`; тропарь и кондак храма на литургии |
| `-lang cu\|en`, `-lang2 en` | язык и второй язык параллельно (непереведённые тексты — по-церковнославянски) |
| `-mode laity\|kliros` | вид: для молящихся или клиросный (`render`, `serve`) |

Веб-сервер принимает те же параметры в запросе
(`?date=…&service=…&mode=…&temple=…&psalmody=…`).

Церковнославянский текст — в Юникоде; нужны шрифты Ponomar Unicode или
Monomakh.

## Источники и правила

**Ирмологий** (`orthlib.irmologion`):
- **Библейские песни** — тремя наборами: вседневные, «в недели и праздники»,
  великопостные (`ir.ode.<песнь>.<набор>.<n>`), с отметками мест «на 14 / 8 /
  6 / 4».
- **Припевы 9-й песни на праздники** (`ir.pripev.<праздник>.*`): в самый
  праздник вместо «Честнейшую», к каждому тропарю — свой припев.

**Чин службы по знаку святого в Типиконе:**
- **Чёрный знак (шестеричная служба) и без знака:** вседневные песни,
  катавасия по 3-й, 6-й, 8-й и 9-й песням, славословие читается, хвалитны
  читаются.
- **Красный знак** (великое славословие поётся, полиелей, бдение), а также
  воскресенья, праздники, предпразднства и попразднства: песни «в недели и
  праздники», катавасия по каждой песни.
- **Знаки берутся из месяцеслова Типикона** (гл. 48, `ty.<ММ>.<ДД>.sign.<N>`
  — по каждой памяти дня): `<(:.>` чёрный — шестеричная; тот же знак
  красным — славословная; красный `+` — полиелей; `\+/` — бдение святому (средний праздник, гл. 47: «крст с полукружием… бдение совершается»);
  `(+)` — бдение; без знака. Чин дня — по старшему знаку его памятей.
- **Минея** («славословие великое», `me.<день>.matins.great_doxology`)
  учитывается только в предпразднство и попразднство, у которых своего
  знака нет, и если Типикона нет в корпусе. Где Минея ставит великое
  славословие, а Типикон даёт чёрный знак или никакого (10.14, 10.21, 05.29,
  06.01…), решает Типикон.
- **Красный знак на вседневной утрене:** по 9-й песни «Свят Господь Бог
  наш», на хвалитех стихиры святого, великое славословие поётся, стиховны
  нет.

**Кафизмы — по «Уставу о Псалтири»** Следованной Псалтири:
- летний и зимний порядок;
- в праздник зимнего порядка на утрене две кафизмы, а третья — на вечерне
  того же дня.

**Общая Минея** (`orthlib.obschminea`, ключи `om.<чин>.*`) восполняет то,
что день Минеи со знаком оставляет ей:
- **Что берётся:** общие паремии (гл. 39), прокимен утрени, а на литургии —
  прокимен, Апостол, аллилуиа, Евангелие и причастен (гл. 40).
- **Как выбирается чин святого:**
  1. по собственной ссылке дня («на литургии служба преподобническая»,
     «чтения три стительская», «евангелие стительское»);
  2. иначе — по его Апостолу и Евангелию;
  3. иначе — по заглавию.
- **Пометки:** скопированное помечено `copied_from`, а если чин угадан по
  заглавию — ещё и `rank_from_title`.

**Катавасия воскресной утрени** — по временам года, из
`data/calendar/katavasia.yaml`. **Посвящения храмов** —
`data/calendar/temples.yaml`.

## Покрытие

✅ поддерживается · ⚠️ частично (см. примечание) · ❌ ещё нет (служба
сообщает «ещё не реализовано») · — в этот день не совершается.
Вечерня указана при том дне, к которому она относится: служится она накануне
вечером.

### Обычный год (Минея и Октоих)

| День | Вечерня | Утреня | Часы | Литургия |
|---|---|---|---|---|
| Будний день (пн–пт), святой без знака | ✅ вседневная | ✅ вседневная | ✅ | ✅ |
| Будний день, святой со знаком (полиелей, бдение) | ✅ великая / бдение ¹ | ✅ праздничная ² | ✅ | ✅ |
| Будний день в попразднство или отдание | ✅ вседневная | ❌ | ✅ | ❌ |
| Двунадесятый непереходящий праздник в будни | ✅ бдение | ✅ праздничная | ✅ | ✅ |
| Суббота (любая) | ✅ вседневная или бдение (в пятницу вечером) | ❌ | ✅ | ⚠️ ⁴ |
| Воскресенье, святой без знака | ✅ бдение, без литии | ✅ ³ | ❌ | ✅ |
| Воскресенье, святой со знаком | ✅ бдение (с литией, если она есть в Минее) | ✅ ³ | ❌ | ✅ |
| Воскресенье в попразднство или отдание | ✅ бдение | ✅ ³ | ❌ | ✅ |
| Воскресенье со своими чтениями (пред и по Рождестве, пред и по Богоявлении, пред Воздвижением) | ⚠️ кроме недели пред Воздвижением (предпразднство с Обновлением) | ⚠️ кроме недели пред Воздвижением | ❌ | ❌ |
| Господский праздник в воскресенье (Воздвижение, Сретение, Преображение) | ✅ бдение | ✅ праздничная | ✅ | ✅ |
| Богородичный праздник в воскресенье | ✅ бдение | ✅ ³ | ⚠️ без воскресного тропаря | ✅ |
| Рождество Христово, Богоявление и их навечерия (Царские часы) | ❌ | ❌ | ❌ | ❌ |
| Святой со знаком, чьих чтений Минея не даёт (≈10 дней) | ❌ | ❌ | ✅ | ❌ |

¹ Недостающие в Минее чтения берутся из Общей Минеи по чину святого.
² Нужно утреннее Евангелие в Минее (или «евангелие святительское /
преподобническое»).
³ Октоих вместе с Минеей: утреннее евангелие из 11 воскресных (счёт от
Недели всех святых), «Ангельский собор», ипакои, степенны и прокимен гласа;
катавасия по временам года.
⁴ По гл. 12 Типикона («Бог Господь»): «Апостоли, мученицы», тропарь и
кондак святого или «Помяни, Господи», «Со святыми упокой», «Яко начатки»;
прокимен, Апостол, аллилуиа, Евангелие и причастен святого — прежде
дневных. В Дмитриевскую родительскую субботу (последняя суббота перед
26 октября; если она приходится на великий праздник — полиелей и выше по
Типикону, великая вечерня в Минее, — то на субботу раньше) после дневных — за упокой: прокимен «Души их во благих
водворятся», Апостол (1 Фес., зач. 270), Евангелие (Ин., зач. 16), стих
аллилуиа и причастен «Блажени, яже избрал». Пока нет: тропарей Октоиха на
блаженнах (в корпусе они только для 2-го и 8-го гласов), мясопустной и
Троицкой родительских суббот (служба Триоди), субботы в попразднство.
Несколько дней ещё не собираются там, где импорт Минеи теряет тропарь или
канон.

## Структура кода

| Каталог | Назначение |
|---|---|
| `calendar/` | юлианские даты, пасхалия, контекст дня (глас, утреннее евангелие, рядовые чтения) |
| `internal/hip` | HIP → Юникод |
| `internal/orthlib` | импорт текстов orthlib.ru |
| `internal/corpus` | хранилище текстов (PostgreSQL) |
| `internal/liturgy` | правила → план → дерево службы → вид → HTML |
| `data/` | шаблоны, правила, переводы интерфейса (i18n), манифест импорта, календарные таблицы |
